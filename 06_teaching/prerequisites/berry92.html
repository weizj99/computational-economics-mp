Scope & the course’s entry routine
  • Enumeration checks all 16 sets; it scales exponentially.
  • Ranking relies on the shared, decreasing crowding term.
  • The course deletes firms and resolves; it does not test every excluded firm’s re-entry.
  • Its stopping rule can retain loss-making firms. A returned set needs further checks before being called an entry Nash equilibrium.

Try it yourself

Check every operating set on your computer.

Download the Python example and run it in the folder where you saved it. It needs Python 3.10 or later with NumPy, and takes under a second. In the course repository, run python lessons/00_prerequisites/berry92.py from the root instead.

python berry92.py

It checks all 16 sets of the four firms at δ = 1, lists the sets that pass the deviation tests and gives the set that ranking by profitability chooses. Add --self-test to run the checks first.

These are the two sets that pass at δ = 1 on this page, with the same deviation gains. Every gain is negative, so no firm wants to enter or to leave. Ranking by profitability chooses AB.
