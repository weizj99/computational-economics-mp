Estimating the economy

Explore 512 parameter candidates, the economies they produce, and their fit to three observed moments. Repeated for every year from 1980 to 2023, this search gives the course’s final result, shown in 44 searches, one view.

The economic model is based on De Loecker, Eeckhout and Mongey (2026). For the low-discrepancy sequence behind the search design, see Sobol (1967).

N stays continuous in the search; M = floor(N) is the number of potential firms per market. Entry and exit determine how many operate. ζ picks φ, the fixed labor of each operating firm, which stays the same in period 2. Follow the economy → moments calculation in lesson 02.

Data Model

Subtract the annual target from each model moment. Square each gap, multiply by its fixed weight, then add the three contributions. Rate gaps enter this calculation as fractions; the rate columns display % and percentage points.

Try it yourself

Search 64 candidates for 2000 on your computer.

Download the code and data, unpack them, and run this command in the unpacked folder or at the root of the course repository. It needs Python 3.10 or later with NumPy and SciPy. One economy for 2000 takes about 4.5 seconds, so the 64 candidates take about five minutes on one core; add --workers 4 to solve four at a time.

python lessons/03_estimation/search_year.py --year 2000 --points 64

The script maps the first 64 of the 512 Sobol points into the search box for 2000, solves each economy, scores it with the three weighted squared gaps and prints the lowest loss. It then compares every economy with the saved candidates that this page shows.

Each error pools the 44 years and three draws. With the search’s own draws the three errors are 0.223 pp, 0.03971 and 0.103 pp. Reallocation moves most in the 11 years with ζ ≥ 1 (1986–1995 and 2002): there φ is ζ times the largest break-even value, which changes more from draw to draw than the value ζ picks when ζ < 1. Nothing is estimated again.

Method & interpretation
  1. 01512 pointsσ, N, ζ · same Sobol design
  2. 02SolveM = floor(N) · φ from ζ
  3. 03ScoreThree squared gaps · fixed weights
  4. 04SelectLowest loss in this finite set
  • Plot: σ–N projection; ζ also changes.
  • Weights: inverse 44-year sample variances.
  • Display: rates in %; objective uses fractions.
  • Read with care: boundaries, draw sensitivity, early-1980s markup above target.
